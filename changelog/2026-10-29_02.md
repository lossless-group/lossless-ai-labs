## Why Care?

The context-vigilance kit names a baseline every doc should carry: `title`,
`date_created`, `date_modified`, `site_uuid`, `hex_code`, and `authors`.
Aggregators, the splash, and the Chroma corpus read those fields. In ai-labs
45 of 47 docs already had all six; this fills the last two gaps and brings a
handful of values up to the kit's standard spelling.

Facts only: every added value comes from git history, no existing value
changed meaning, and no date is the day of the sweep.

## What's New?

- **`date_modified: 2026-08-18`** on `When-Claud-Code-and-When-Pi.md`, the
  date of its last commit before this sweep.
- **`authors: [Michael Staton]`** on the SurrealDB MCP plan, its only human
  committer (agent co-authors left out).
- **`augmented_with` as a list** on the In-App Agent Chat core package spec,
  its value unchanged.
- **Tags in Title-Case:** `reach-edu` → `Reach-Edu`, `humain-vc` →
  `Humain-VC` (two docs), and `pnpm` → `Pnpm`, matching the spellings used
  elsewhere in the tree.
