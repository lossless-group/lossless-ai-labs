## Why Care?

`studies/context-v/` is where ai-labs plans its studies: the proposals for new
reference collections, the prompt for starting one, and the three-step method
for comparing a collaborator's codebase with ours. [[2026-10-29_01]] made
ai-labs' main `context-v/` an
[Open Knowledge Format](https://github.com/GoogleCloudPlatform/open-knowledge-format)
(OKF) v0.2 bundle and left this one for later. Now it's a bundle too, so any
OKF tool can list what's here and what each doc is for.

This is a compliance change, not a content change. No doc's body, dates,
version, or status moved.

## What's New?

- **`type:` on all 8 docs**, added as the last frontmatter line of each:
  3 `Explorations`, 3 `Plans`, 2 `Prompts`.
- **`studies/context-v/index.md`**: the bundle's own root index, declaring
  `okf_version: "0.2"` and listing the three folders.
- **One `index.md` per folder**, one line per doc, using its lede (or its
  title alone, for the three docs without one).

## Under the Hood

- Every edit was made by hand, one file at a time. The doc diff is 8 added
  `type:` lines and nothing removed.
- The pinned study repos under `studies/` are other projects' code and were
  not touched.
- The splash roll-up copies this folder, and the splash already skips
  `index.md`, so the new indexes don't appear as pages.

Part of the tree-wide sweep planned in the context-vigilance kit:
`ai-labs/context-vigilance-kit/context-v/plans/Retrofit-Every-Repo-to-OKF-Then-the-Kit-Frontmatter.md`.
