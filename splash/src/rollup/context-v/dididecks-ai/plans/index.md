# Plans

* [Plan: Add /remake-deck as a command in the DidiDecks in-app agent chat](Add-Remake-Deck-Command-to-In-App-Agent-Chat.md) - Let a user type /remake-deck in the app's AI command lane and get N verified design variants back as a reviewable proposal, by running the existing remake pipeline on a worker instead of in a terminal.
* [Componentize Slides and Establish Component Library](Componentize-Slides-and-Establish-Component-Library.md) - Walk calmstorm-decks slide by slide, extracting inline HTML+CSS into a taxonomized Astro component library plus the design system behind it.
* [Extract @lossless-group/dididecks-player and ship a gated decks page on humain-web](Extract-Didideck-Player-Package-and-Ship-Humain-Decks-Page.md) - Split the viewer half of @dididecks/shell into a standalone, publishable package (LFM-shaped), keep the rater and triage tools in dididecks, and give humain-web a passcode-gated decks page built on the player.
* [Init Chroma Decks Client-Site](Init-Chroma-Decks-Client-Site.md) - Stand up `client-sites/chroma-decks` for a founder raising a round, using the engagement to harden calmstorm-decks into a reusable baseline.
* [Init DidiDecks as Core Submodule of AI-Labs](Init-DidiDecks-as-core-Submodule-of-AI-Labs.md) - Carve dididecks-ai out into its own repo and re-attach it to ai-labs as a git submodule, with branch-aligned tiers.
* [Integrate reach-edu-hub into the shared @dididecks/shell — scroll-UI first, adopting the shell's /scroll/[deck]/[variant] URL convention](Integrate-Reach-Edu-Hub-into-Dididecks-Shell.md) - reach-edu-hub is the last client-site outside `@dididecks/shell` — onboard it scroll-first onto the `/scroll/[deck]/[variant]` convention.
* [Lift chroma-decks' generic layouts, utilities, and registry-derivation helpers into the shared @dididecks/shell so every client-site inherits the same primitives instead of forking from chroma](Lift-Chroma-Decks-Generic-Code-into-Shared-Shell.md) - Chroma still owns deck-generic primitives that predate the shell carve-out — SlideShell, mode-switcher, deck-overview. Lift them.
* [Migrate DidiDecks off deprecated @astrojs/db and bump @dididecks/shell to Astro 7](Migrate-Off-AstroDB-and-Bump-Shell-to-Astro7.md) - @astrojs/db is deprecated and the shell pins everyone to Astro 6. Move the client-site auth layer to direct @libsql/client (Turso) and republish the shell for Astro 7 — starting with eventcut-ai as the pilot.
* [Phase A+ — In-Deck Ranking, Shared Nav Chrome, and a Working /play Runtime](Phase-A-Plus-In-Deck-Ranking-Shared-Nav-and-Play-Runtime.md) - Closes Phase A's three gaps — shell-injected global nav, an in-scroll `<SlideRankPill>`, and a working `/play/[deck]/[variant]/[slot]`.
* [Phase A++ — Play Fidelity, In-Play Ranking, and Variant URL Safety](Phase-A-Plus-Plus-Play-Fidelity-In-Play-Ranking-and-Variant-URL-Safety.md) - Three Phase A+ gaps: `/play/pitch/proto/` 404s on a slot-less variant, Play chrome reads as a dev tool, and no rank pill inside `/play`.
* [Port Enhanced-v2 Scroll Slides to Static 16:9 Play Slides for PDF Export](Port-Enhanced-v2-Scroll-Slides-to-Static-16x9-Play-Slides-for-PDF-Export.md) - Port chroma's 16 enhanced-v2 scroll sections into static 16:9 play slides, then stack them on a print route so ⌘P yields a shippable PDF.
* [Redesign TOC as a Deck-Level Dual-Surface Review Matrix](Redesign-TOC-as-Deck-Level-Dual-Surface-Review-Matrix.md) - A deck-level matrix replaces the port-status TOC: variants as columns, two review chips per cell, so shippability reads at a glance.
* [Refactor data-assets audit for per-asset quality ratings, brand-asset disambiguation, and deck-render guards](Refactor-Data-Assets-Audit-for-Brand-Quality-Ratings-and-Render-Guards.md) - Split the audit's generic 'logo' into favicon, trademark, wordmark, og:image — each with its own quality rating and a render guard.
* [Refactor scroll-ported slides into true static play-format slides (per-client, repeat for every deck)](Refactor-Scroll-Ported-Slides-to-Static-Play-Format.md) - A reusable procedure for stripping scroll idioms — vw/vh units, reveals, marquees — from copied slides so `/play` and `/print` render them.
* [Plan: Remake a source deck into N clean-room design variants](Remake-Source-Deck-into-Design-Variants.md) - The orchestrator plan. As VP Eng you extract a source deck, audit the extraction, fan out N clean-room designers, refactor each design into Astro sections, wire the registry, and prove every variant plays in the Scroll-UI shell.
* [Restore Calmstorm's nav-chrome elegance as themable shell primitives (separate structure/behavior from styling)](Restore-Calmstorm-Nav-Elegance-as-Themable-Shell-Primitives.md) - PlayChrome traded calmstorm's floating glass capsule for a heavy dark bar — lift the calmstorm chrome back as themable shell primitives.
* [Scaffold eventcut-ai and angelhouse client-sites from the chroma-decks template](Scaffold-EventCut-and-AngelHouse-Client-Sites.md) - Two new gated deck client-sites — eventcut-ai (eventcut.ai) and angelhouse (angelhouse.life) — stood up via the proven per-client-repo ritual, cloning chroma-decks' wired auth + shell rather than the deferred shared-host idea.
* [Stand Up @dididecks/shell and Ship the Chroma TOC + Slide-Ranking UI](Stand-Up-Dididecks-Shell-and-Ship-Chroma-TOC-Ranking.md) - Phase A: scaffold `apps/deck-shell/` as an Astro integration and ship the TOC + slide-ranking UI into chroma-decks via workspace link.
