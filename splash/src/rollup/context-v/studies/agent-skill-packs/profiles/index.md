# Profiles

* [gstack — Profile](Profile__gstack.md) - A virtual engineering team as 64 role skills plus a router, each SKILL.md rendered from a template and adapted to thirteen harnesses; its own eval says it does not raise the fix rate.
* [Matt Pocock Skills — Profile](Profile__mattpocock-skills.md) - Thirty-nine skills sorted by maturity rather than topic, split into ones you type and ones the agent may reach for, held in shape by a written scope bar, recorded rejections, and a router re-synced on every change.
* [pstack — Profile](Profile__pstack.md) - Fifty-eight skills, twenty-four of them one-rule principles, nearly all reached through one router that matches a task to a playbook; shipped with two plugin manifests, a guide, and a mirror that logs every upstream check.
* [seo-skills — Profile](Profile__seo-skills.md) - Thirty SEO, content, copy, and marketing skills sold to founders and marketers on one promise: every skill ends in a merged PR or a file in the repo, not an audit PDF.
