# Profiles

* [ADHD Claude Skill — Profile](Profile__ADHD-Claude-Skill.md) - Write the outcome down before any code moves, then park every tangent in the workstream it actually belongs to.
* [ADHD Copilot — Profile](Profile__ADHD-Copilot.md) - A coaching skill that splits itself in two: one half talks the user out of being stuck, the other half quietly takes notes on what worked and asks permission before keeping them.
* [ADHD Skills — Profile](Profile__ADHD-Skills.md) - The agent runs the ritual and asks the hard question; the user does the writing, and the agent never touches the files.
* [ADHD Study Coach — Profile](Profile__ADHD-Study-Coach.md) - It doesn't invent an ADHD study method; it takes retrieval practice and spacing, which already work, and removes the reasons an ADHD learner stops doing them, starting with having to remember to ask for review.
* [AuDHD Executive Function — Profile](Profile__AuDHD-Executive-Function.md) - The far end of the study: the agent stops advising and becomes the user's executive function, handing over a daily HTML workbench where every item is text to copy, a link to click, or a box to check.
* [Claude ADHD Skills — Profile](Profile__Claude-ADHD-Skills.md) - Give the agent a clock and a sticky note, then let an Obsidian vault remember yesterday: time blindness solved with two `UserPromptSubmit` hooks and a 4-column SQLite table.
* [DSH ADHD Copilot — Profile](Profile__DSH-ADHD-Copilot.md) - An ADHD coaching skill turned into a deterministic keyword router: one `adhd_breakdown` tool that maps a stuck user to one of eight modules and hands back a single next action under 60 seconds.
* [I Have ADHD — Profile](Profile__I-Have-ADHD.md) - A 142-line ruleset that changes the shape of every reply (action first, numbered steps, five-item lists) and does nothing else: no state, no nudges, no task flow.
* [ND Skills — Profile](Profile__ND-Skills.md) - Twenty-five small skills, each named for one executive-function construct or barrier, kept always-on by a 24-line index block and fired by numeric thresholds; v2 adds a router, rules mined from 3,278 real sessions, and a consent budget for every unprompted nudge.
