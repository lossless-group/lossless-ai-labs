## Why Care?

The first time a partner used MemoPop from Claude, they could change a memo, but couldn't see the result anywhere they trust. The memo they show their LPs lives on their firm's site, and that site was showing a copy pulled in by hand days earlier.

As of this weekend that loop is closed. A partner asks Claude to change a memo, Claude compiles it through the MemoPop connector, and a refresh of the memo's page on the firm's own site shows the change.

## What's New?

- **Everything the first partner test found is fixed**, and partners can now edit finished memos: section and final edits, outline changes, and revisions.
- **Citations point at the right sources.** Memos used to number sources per section, so a later section's footnote could open an earlier section's source. New memos use a hex key per source, numbered only when rendered. A repair tool fixed the affected memos without changing a word of their prose.
- **Previews.** Agents call a `preview` tool to show a section or memo exactly as it will render, using Lossless Flavored Markdown on the server, instead of rendering markdown themselves.
- **Firm sites read memos from MemoPop.** A site key per firm reads that firm's latest compiled memos. When a memo compiles, MemoPop sends the site a signed notification, so the site can cache memos for speed and still show each new version right away.
- **Deal folders upload cleanly.** The uploader that moves a firm's local deal folders to the server no longer carries macOS metadata files, and records each upload in the server's history in full.

## How it Fits Together

```
Claude (partner) ──MCP──▶ MemoPop connector ──compile──▶ compiled memo
                                   │                            │
                                   │ signed memo.compiled       │ GET /site/v1/…/memo (site key)
                                   ▼                            ▼
                           firm site hook  ──clear cache──▶  firm site LP page
```

The desktop app is unchanged by this round. The work sits in the orchestrator (the connector and pipeline) and in the firm's site. This repo only moves its pointer to the orchestrator.
