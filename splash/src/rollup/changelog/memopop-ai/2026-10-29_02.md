## Why Care?

The context-vigilance kit has a baseline frontmatter template: every doc
carries a title, its creation and last-modified dates, an ID pair, and its
authors, with list-valued fields written as lists. Tools that roll MemoPop's
design record up into the splash and the corpus read those fields, and a
bare string where a list belongs is one more special case for each of them.

Every value written here is a fact: a date from `date_authored_initial_draft`
or git history, or a value already in the doc, reshaped. No date was set to
today, and no version, status, or body line changed.

## What's New?

- **Missing dates, filled from facts.** Five docs gain `date_created` from
  their `date_authored_initial_draft`, and `date_modified` from their last
  commit before the sweep. `Issues-after-First-Run` in memopop-native gains
  `date_modified` from its last content commit; its most recent commit was
  only a rename.
- **`augmented_with` as a list.** Twenty docs wrote it as a bare string;
  each is now a one-item YAML list with the same text.

Titles, IDs, and authors were already present on every doc, and no doc
used the legacy `version:`, `created:`, or `date:` keys.

Part of the tree-wide sweep planned in the context-vigilance kit:
`ai-labs/context-vigilance-kit/context-v/plans/Retrofit-Every-Repo-to-OKF-Then-the-Kit-Frontmatter.md`.
