# hope-ai's Docs Become a Bundle Any Agent Can Read

## Why Care?

The planning docs behind the PSP skill and dashboard live in `context-v/`. Until today, an agent landing here had to open each file to learn what it was. Now the folder is an Open Knowledge Format (OKF) v0.2 bundle: one index at the top, one per folder, and every doc stating its own type. Any OKF reader, ours or anyone's, can list what's here and what each doc is for without opening a thing.

## What's New?

- **The dashboard spec declares `type: Specs`**, the name of the folder it lives in. That one line is the whole OKF rule.
- **`context-v/index.md`** marks the bundle with `okf_version: "0.2"` and lists its folders.
- **`context-v/specs/index.md`** lists the spec with its lede.

## Under the Hood

- Part of the tree-wide OKF sweep; see the Context Vigilance Kit's plan, [[Retrofit-Every-Repo-to-OKF-Then-the-Kit-Frontmatter]].
- The edit was made by hand. No script touched any frontmatter, and no dates on the spec changed: this is a compliance change, not a content change.
- The spec already carried the kit's full baseline frontmatter, so the sweep's second phase had nothing to add and gets no entry of its own.
- Empty folders (`plans/`, `explorations/`, `issues/`) keep their `.gitkeep` and get no index until they hold a doc.
