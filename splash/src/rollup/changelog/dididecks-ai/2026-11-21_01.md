## Why Care?

GitHub showed 52 open security alerts on dididecks-ai, two of them critical.
They're all in the splash site. Only six still applied. The rest were fixed
three weeks ago, but GitHub's dependency graph stopped rescanning the repo,
so they never closed.

***

## What's New?

- **Astro 7.4.4 → 7.4.13** in the splash. Closes the attribute-injection XSS
  and the image-endpoint file read (alerts #53–56).
- **fflate forced to 0.7.5 or later.** satori pins 0.7.3 exactly, so a pnpm
  override in `splash/pnpm-workspace.yaml` patches it without downgrading
  anything. `pnpm audit` now reports no known vulnerabilities.
- **A plan for the stale alerts:** rescan, dismiss if needed, and turn on
  Dependabot security updates. See
  `context-v/plans/Clear-Splash-Dependabot-Alerts-2026-11-21.md`.

The build is unchanged at 64 pages, and pnpm 10.15, the version CI uses,
installs the lockfile with `--frozen-lockfile`.
