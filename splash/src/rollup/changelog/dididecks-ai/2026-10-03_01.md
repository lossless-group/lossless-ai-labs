## Why Care?

Remaking a client's deck worked well when Michael drove it in conversation with
Claude Code. It depended on knowing what to say: extract everything first,
check the extraction, keep designers from copying the original, split the result
into Astro sections, and make sure it plays. Collaborators who don't work by
chatting with a coding agent had no way in.

Now it's one command:

```text
/remake-deck "Edit on the Spot" eventcut-ai client-sites/eventcut-ai/inputs/2026-08-02_EventCut_Deck/EventCut-Deck-2026-08-02.pdf
```

## What's New?

- **`/remake-deck`.** The agent acts as orchestrator and hands each job to a
  separate subagent:
  - **Extract:** pulls the transcript, the layout of each slide, the data as
    JSON/CSV, and the images out of the source deck.
  - **Audit:** a second agent checks that extraction against the original.
  - **Design:** three designers each make one coherent HTML + Tailwind deck from
    the content alone, never seeing the original layout or each other's work.
  - **Refactor:** each design becomes `Section__<Name>.astro` files rendered from
    one `index.astro`.
  - **Verify:** each variant is driven through the shell in a real browser.
- **Facts stay locked.** Designers may rewrite copy, but every number traces
  back to the source deck. Conflicts inside the client's own deck are flagged
  for the client, not quietly fixed.
- **Works beyond Claude Code.** The same procedure is a skill
  (`context-v/agent-skills/remake-deck/`) for Claude desktop, pi, Cursor, and
  Codex. Chats without subagents run the roles in sequence.
- **Commands are now listed** in `README.md` → "Commands".

## How it was proven

A dry run on EventCut's 15-slide source deck produced three distinct
variants ("Grid", "Control Room", "Storyboard"). All passed the fact check, and all
played in the shell. The subagents reported about thirty points of friction
along the way, and those were folded back into the prompts before this
shipped. Among them: clean rooms leaking through a shared scratch folder,
parallel builds clobbering each other, and the passcode login needing an
`Origin` header. The dry-run output was not kept.
