# The Vector Databases Study's Profiles Become an OKF Bundle

## Why Care?

This study pins six vector stores (Chroma, Qdrant, Weaviate, Milvus, LanceDB, pgvector) and profiles each against its upstream code. Until today an agent had to open each profile to learn what it was. Now `context-v/` is an Open Knowledge Format (OKF) v0.2 bundle, so any OKF reader can list the profiles and what each one argues without opening a thing.

## What's New?

- **All six profiles declare `type: Profiles`**, the Train-Case name of the folder they live in.
- **`context-v/index.md`** marks the bundle with `okf_version: "0.2"` and lists its one folder.
- **`context-v/profiles/index.md`** gives one line per profile, using its lede.
- **This `changelog/`** is new; this is its first entry.

## Under the Hood

- Part of the tree-wide OKF sweep; see the Context Vigilance Kit's plan, [[Retrofit-Every-Repo-to-OKF-Then-the-Kit-Frontmatter]].
- Every edit was made by hand, one file at a time. The doc diff is six added `type:` lines and nothing removed. No dates moved: this is a compliance change, not a content change.
- The pinned upstream repos beside `context-v/` are untouched.
