# The Vector Store Profiles Carry the Kit's Metadata Template

## Why Care?

[[2026-11-01_01]] made this study's `context-v/` an Open Knowledge Format bundle. This pass brings the six profiles up to the Context Vigilance Kit's baseline frontmatter, so a dashboard over the tree can name them, date them, credit them, and group them with the other reference material.

## What's New?

- **`status: Reference` on all six.** A profile describes an upstream tool as studied: something an agent consults, not work that ships.
- **A `title`** on each, taken from its first heading.
- **`date_modified: 2026-08-18`**, the date of each file's last commit before this sweep.
- **`authors: Michael Staton`**, the only human committer of each file.

## Under the Hood

- Part of the tree-wide OKF sweep; see the Context Vigilance Kit's plan, [[Retrofit-Every-Repo-to-OKF-Then-the-Kit-Frontmatter]], and the status vocabulary in the context-vigilance skill's `status-discipline.md`.
- Every edit was made by hand, frontmatter only. No body line changed, no existing key or date moved, and today's date was written into no existing doc.
- The profiles already had `site_uuid`, `hex_code`, and `date_created`, and carry no `tags`, so nothing needed minting or normalizing.
