# Vector Database Pins Move to November 2026; Profiles Catch Up

## Why Care?

The six profiles in this study cite upstream code by `file:line`. After six months and roughly 11,700 upstream commits, many of those citations pointed at the wrong lines or at files that no longer exist, and a few of the profiles' claims had become false. This pass moves every pin to the head of its upstream default branch and brings each profile back in line with the code.

## What's New?

- **Weaviate's license changed.** Code outside a new `wl/` directory stays BSD-3-Clause; code inside it is enterprise-licensed and enabled by license key. Namespaces, backup deduplication, database-user expiry, and self-recovery live there. Weaviate also stopped applying a server-wide default vectorizer: collections without one now get `none`.
- **Milvus 3.0 went GA** (July 2026, now at 3.0.6), with row-level security, external collections that read from snapshots, S3, or Apache Paimon, and a refactored compaction subsystem.
- **Qdrant 1.20 ranks BM25 on the server** through a new `Text` query over text indexes. The filter push-down code the profile centers on moved into a new `read_view/dispatch.rs`, with the same behavior.
- **LanceDB renamed its products** to LanceDB Embedded and LanceDB Enterprise, moved its Lance format dependency from v7 to v15, and grew its Rust crate from about 45k to about 155k lines, mostly Enterprise client surface. The `.lance` portability argument still holds.
- **pgvector shipped five patch releases** (0.8.3 to 0.8.7) fixing HNSW vacuum corruption and IVFFlat build overflows; master's unreleased 0.9.0 adds async I/O and drops Postgres 13 and 14.
- **Chroma 1.6.0** fixed a run of local HNSW integrity bugs and added conditional transactions, which embedded mode does not support. Hybrid `search()` is still unavailable locally.

## Under the Hood

- Each profile has a new "Changes since the previous pin" section with old and new SHAs, commit counts, releases in range, and the changes that matter to its thesis, each with a path at the new pin.
- Every cited path was checked at the new SHA, and line citations were re-located with `git grep`. Moved code was re-cited at its new home (for example Qdrant's `hnsw/search.rs` to `hnsw/read_view/`, Milvus's `internal/proxy/task.go` to `internal/proxy/ddl/task.go`, LanceDB's `CLAUDE.md` quote to `AGENTS.md`).
- The Milvus profile's `pinned_sha` frontmatter key now records the new pin.
- The study README gained a "Pins last refreshed 2026-11-23" table and updated entries for Chroma, Qdrant, Weaviate, Milvus, LanceDB, and pgvector.
- The submodule pointer bump itself is committed separately by the study's maintainer.
