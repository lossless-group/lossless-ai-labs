# Sync Study Pins Move to November 2026; Rclone UI Turns Out Rewritten

## Why Care?

This study answers where history should live when a folder is shared with a non-technical client over blob storage. Its answers rest on line-level readings of pinned upstream code. Three months of upstream work had moved some of those lines, and in one case removed the code a finding depended on. The profiles now describe the code as it is today, and each one says what changed since it was first read.

## What's New?

- **Eight of nine submodules now sit at their upstream tips** (dates from 2026-10-16 to 2026-11-23). The README has a "Pins last refreshed 2026-11-23" table with old and new dates, commit counts, and latest releases.
- **Rclone UI was rewritten** from Tauri/Rust to Go on Wails 3 and now calls itself the official rclone GUI under `github.com/rclone/rclone-ui`. The cross-platform launchd/crontab/Task Scheduler layer is deleted; schedules run inside the app, and rclone is linked as a library. The profile and its index line now say so, and point to the old pin for the scheduler code.
- **jj split its library into crates** (`jj-core`, `jj-git-backend`, `jj-simple-stores`, `jj-local-util`) and added a sixth store kind, a workspace store. The profile's "five backends" claim is now "six stores", and every path it cites was re-located. Still no object-storage backend.
- **Automerge added authors**: an `Author` distinct from the per-session actor, released in `js/automerge-3.5.0` and `rust/automerge-0.12.0`. Still no truncate or GC.
- **restic `v0.20.0`** fixes two restore issues and adds `prune --json`; snapshots still have no free-text reason.
- **Syncthing `v2.1.7`** now compares block hashes when reconciling a receive-only folder, which tightens the profile's main finding.
- **Seafile server** fixed a block-order upload corruption and a GC race on network filesystems. Kopia had no release in range and nothing the profile cites changed.

## Under the Hood

- Each profile gains a "Changes since the previous pin" section with old and new SHAs, commit counts, releases, and the changes that bear on its thesis, each citing a path at the new pin. Drifted line numbers were corrected throughout.
- **git-annex was not refreshed.** Its upstream, `git.joeyh.name`, serves dumb HTTP and the fetch fails with "Cannot obtain needed blob". It stays at `6bc17908` (August 2026), and its profile is unchanged.
- The submodule gitlinks are left for a separate commit.
