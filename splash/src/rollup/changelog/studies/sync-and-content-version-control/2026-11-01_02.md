# The Study's Profiles Read as Reference, Not Drafts

## Why Care?

A profile describes an upstream tool as it was read at its pin: an accurate account of how that tool works, which an agent consults rather than finishes. All eight still said `Draft`, the authored-day default, so a workflow dashboard would have listed them as unfinished work. Now they say what they are.

## What's New?

- **All 8 profiles move from `Draft` to `Reference`**, the kit's status for a standing doc that explains how things are. None is a placeholder, and none says its pin is outdated.
- **All 8 gain a `title`**, taken from the doc's first heading. The existing `name:` key stays.
- **Five Lossless repo names leave `tags`** where the body already names the repo: `Flave` from Automerge and Jujutsu, `Corpora-Builder` from Kopia and restic, `Augment-It` from Syncthing. Each profiled tool's own name stays, since it is the doc's subject.

## Under the Hood

- Part of the tree-wide OKF sweep's second pass; see the Context Vigilance Kit's plan, [[Retrofit-Every-Repo-to-OKF-Then-the-Kit-Frontmatter]].
- Every edit was made by hand, frontmatter only. Dates, IDs, and authors were already present and are unchanged; no `date_modified` moved.
