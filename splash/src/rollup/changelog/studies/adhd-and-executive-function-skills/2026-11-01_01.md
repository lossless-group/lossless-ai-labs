# The ADHD Study's Nine Profiles Become a Bundle Any Agent Can Read

## Why Care?

This study's `context-v/` holds one source-cited profile per pinned repo: nine takes on where an agent skill puts its help for ADHD and executive-function limits. Until today an agent had to open each file to learn what it was. Now the folder is an Open Knowledge Format (OKF) v0.2 bundle, so any OKF reader can list the profiles and what each one argues without opening them.

## What's New?

- **All 9 profiles declare `type: Profiles`**, the Train-Case name of the folder they live in.
- **`context-v/index.md`** marks the bundle with `okf_version: "0.2"` and lists its one folder.
- **`profiles/index.md`** lists the nine profiles, one line each, using each profile's lede.

## Under the Hood

- Part of the tree-wide OKF sweep; see the Context Vigilance Kit's plan, [[Retrofit-Every-Repo-to-OKF-Then-the-Kit-Frontmatter]].
- Every edit was made by hand, one file at a time: nine added `type:` lines, nothing removed, no dates moved.
- The nine pinned upstream repos beside `context-v/` are their own repos and were not touched.
- This is the study's first changelog entry, so it also starts `changelog/`.
