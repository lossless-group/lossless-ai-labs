# The ADHD Study's Profiles Carry the Kit's Metadata Template

## Why Care?

[[2026-11-01_01]] made this study's `context-v/` an Open Knowledge Format bundle. This pass brings the nine profiles up to the Context Vigilance Kit's frontmatter template, so a dashboard or roll-up can show each profile by its title, author, and date without opening it, and can tell that these are reference material rather than work in flight.

## What's New?

- **A `title` on every profile**, taken word for word from its first heading.
- **`status: Reference` on every profile.** Each one describes an upstream repo as it stood at its pin, which is what `Reference` means: a doc agents consult.
- **`authors`** from the profiles' only human committer, and **`date_modified`** from the commit that added them.

## Under the Hood

- Part of the tree-wide OKF sweep; see the Context Vigilance Kit's plan, [[Retrofit-Every-Repo-to-OKF-Then-the-Kit-Frontmatter]], and the status vocabulary in the context-vigilance skill's `status-discipline.md`.
- Every edit was made by hand, frontmatter only. No body line changed, no existing value changed, and today's date was written into no existing doc.
- The profiles already had their IDs, `date_created`, and `lede`; there were no tags, version keys, or bare-string lists to normalize.
