# Native-Shell Study Pins Move to November 2026; OpenAgent Goes Private

## Why Care?

This study compares how desktop chat apps handle state, context switching,
local storage and MCP. Its profiles cite upstream source by path and line, so
they go stale as the upstreams move. Every submodule now sits at its upstream
tip, and each profile that moved has a section saying what changed and whether
the profile's main claim still holds. In one case it no longer can be checked.

***

## What's New?

- **OpenAgent's agent engine is no longer public.** On 2026-07-27 the
  maintainer reset the repo's public history, so the old pin no longer exists.
  Delegation, memory, the MCP client and skills loading moved to a private
  `openagent-runtime` repo. The public repo is now a thin Tauri host that
  supervises a runtime binary over authenticated loopback HTTP, the same shape
  as Dive. The profile's source citations now describe the July code, and its
  lede says so.
- **agent-native resolved two caveats.** A root MIT `LICENSE` was added on
  2026-10-19, and Dispatch no longer keeps a plaintext `vault_secrets` table;
  secrets go into the encrypted `app_secrets` column. Dispatch can now open the
  routed app in a pane beside the chat. The most load-bearing line citations
  were re-located; the framework grew by 2,493 commits.
- **Routa enforces workspace scope in more places.** A2A requests take their
  workspace from the session, and the agents endpoints reject a missing
  `workspaceId` instead of falling back to `"default"`.
- **AnythingLLM's workspace is still a config row.** v1.16 through v1.20 add
  opt-in forwarding of user and workspace identity to MCP servers and re-read
  workspace settings on each agent turn. Line citations were re-located.
- **Small moves.** Dive shipped v0.14.3 (path-component allow-list matching
  in its file tool, sanitized markdown). 5ire added five gateway providers and
  a Gemini stream fix. Kaas and open-vibe did not move.
- **README.** A "Pins last refreshed 2026-11-23" table lists every repo's old
  and new date, commit count and latest release. The Onyx license is
  reconciled (MIT outside `ee/`, enterprise license inside), and its new
  `desktop-v2/` Tauri shell is noted.
