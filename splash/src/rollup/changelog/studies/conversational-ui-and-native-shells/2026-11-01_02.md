# The Study's Profiles Carry the Kit's Metadata Template

## Why Care?

[[2026-11-01_01]] made this study's `context-v/` an Open Knowledge Format bundle. This pass brings the same docs up to the Context Vigilance Kit's frontmatter template, so a reader or a dashboard can tell what each profile is, who wrote it, when it last changed, and that it describes an upstream repo as studied.

## What's New?

- **Titles on all 8 profiles**, taken from each doc's own heading. The profiles' existing `name:` keys stay as they were.
- **`status: Reference` on all 8 profiles.** Each describes a pinned upstream repo as it stood when studied, which is what `Reference` means. The inquiry doc keeps its `Draft`.
- **`date_modified` on all 9 docs**, from each file's last commit before this sweep.
- **Authors on 7 profiles**, from their only human committer. The agent-native profile already had one.

## Under the Hood

- Part of the tree-wide OKF sweep; see the Context Vigilance Kit's plan, [[Retrofit-Every-Repo-to-OKF-Then-the-Kit-Frontmatter]], and the status vocabulary in the context-vigilance skill's `status-discipline.md`.
- Every edit was made by hand, frontmatter only: 39 added lines, nothing removed. No body line changed, no existing date moved, and today's date was written into no existing doc.
- Every doc already had its `site_uuid` and `hex_code`, so no IDs were minted for docs. No tags needed normalizing: the profiled tools' own names stay, since each is the doc's subject.
