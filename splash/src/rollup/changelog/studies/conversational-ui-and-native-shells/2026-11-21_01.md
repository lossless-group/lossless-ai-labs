# Odysseus Joins the Study, Next to Onyx and LibreChat

## Why Care?

ai-labs listed odysseus under `packages/` as pinned AI tooling, but we
never ran or deployed it. We read it the way we read Onyx and LibreChat: as
a self-hosted chat and agent workspace whose design is worth studying. So
it belongs in this study.

***

## What's New?

- **`odysseus/`** is pinned at `3115495` (2026-11-22) and tracks
  upstream `dev`.
- **The README table** has a row for it: a Python web app with a Swift macOS
  wrapper and an MCP host, closer to a breadth reference than a native-shell
  pattern. It's AGPL-3.0.
