# The Open Specs Study's Profiles Become a Bundle Any Agent Can Read

## Why Care?

`open-specs-and-standards/context-v/` holds what this study learned from its pinned upstream repos: one profile per spec, standard, or tool (OpenSpec, Spec Kit, MCP, A2A, AGENTS.md, llms.txt, and the rest), plus an open inquiry across them. Until today an agent had to open each file to learn what kind of doc it was. Now the folder is an Open Knowledge Format (OKF) v0.2 bundle, so any OKF reader can list the profiles and what each one is about without opening a thing.

## What's New?

- **All 14 docs declare their `type`**, the Train-Case name of their folder: `Profiles` (13) and `Inquiry` (1).
- **`context-v/index.md`** marks the bundle with `okf_version: "0.2"` and lists its two folders.
- **Two folder indexes.** The profiles index gives one line per profile, using its lede; the inquiry index lists its one doc by title.

## Under the Hood

- Part of the tree-wide OKF sweep; see the Context Vigilance Kit's plan, [[Retrofit-Every-Repo-to-OKF-Then-the-Kit-Frontmatter]].
- Every edit was made by hand, one file at a time. The doc diff is 14 added `type:` lines and nothing removed. No dates moved: this is a compliance change, not a content change.
- The pinned upstream repos beside `context-v/` are their own repos and were not touched.
- This is the repo's first `changelog/` entry.
