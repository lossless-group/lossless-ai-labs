# Open-Specs Pins Move to November 2026; Profiles Catch Up

## Why Care?

This study pins fifteen open specs and agent tools so we read their real source instead of remembering them. Six months of upstream work had made several profiles wrong in ways that matter: the MCP profile's headline feature is now deprecated, and the llms.txt profile's headline rule no longer exists. Every pin now points at the November 2026 head of its upstream, and every profile says what changed.

## What's New?

- **MCP `2026-07-28` is stateless.** No `initialize` handshake, no sessions, a required `server/discover` RPC, and Multi Round-Trip Requests in place of server-initiated requests. Roots, Sampling, and Logging are deprecated under a new feature-lifecycle policy. The profile and its index lede were rewritten around this.
- **llms.txt v2.** The proposal lets a file cover any path, adds `rel="alternate"` and `rel="describedby"` discovery, and turns `## Optional` into a plain convention. The `llms_txt2ctx` expansion tool left the proposal, though the code still ships.
- **get-shit-done is archived.** The pinned repo's README is now a redirect to `open-gsd/gsd-core`. The profile says so up front and keeps its citations against the last full README.
- **A2A joined the Agentic AI Foundation** (August 2026), its TSC grew to nine companies with Bloomberg, and v1.0.1 shipped.
- **OpenSpec 2.0** installs agent skills only (`/openspec-propose` instead of `/opsx:propose`), and 2.1 installs them globally by default.
- **OpenUI published a written 1.0 specification** for OpenUI Lang, with conformance fixtures, and now has Vue, Svelte, and Angular runtimes.
- **Spec Kit reached v1.4.3**, recast as a process toolkit (SDD plus bug-fix and idea-assessment extensions) with a new `/speckit.converge` step.
- **Symphony is tracker-generic**: GitHub Issues, Jira, Asana, and GitLab adapters join Linear, and tracker credentials stay with the daemon.
- **Superpowers reached v7.0.2**: one reviewer per task instead of two, a rewritten brainstorming skill, and fifteen harnesses.
- **ai-skills** moved its docx, pdf, pptx, and xlsx skills from an all-rights-reserved license to Apache 2.0.

## How it Works

For each repo, the old and new pins were compared with `git log`, `git diff --stat`, tags in range, and the upstream changelog. Every `path:line` citation in each profile was re-located at the new pin, either by mapping unchanged lines between the two versions of the file or by grepping for the quoted text, and corrected where it drifted. Each profile got a `## Changes since the previous pin` section with old and new SHAs, the commit count, releases in range, and the changes that bear on the profile's thesis. Vendor benchmark figures are labeled as vendor-reported.
