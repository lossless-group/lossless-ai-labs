# The Study Follows GSD to gsd-core

## Why Care?

The earlier refresh today left GSD pinned at a commit whose README is only a redirect, so the profile described a repo nobody develops. GSD lives on as GSD Core at `open-gsd/gsd-core`. The study now pins that repo, and the profile describes what ships there.

## What's New?

- **New submodule.** `get-shit-done` is replaced by `gsd-core` → `https://github.com/open-gsd/gsd-core.git`, at `88c50d52d` (2026-11-23), package `@opengsd/gsd-core` v1.23.0, MIT.
- **History note.** The profile records the path from `gsd-build/get-shit-done` to a `get-shit-done-redux` fork (2026-05-22) to GSD Core (2026-05-30), the restarted version numbers, and the fork's own stated reason: the original repo "appears compromised or abandoned."
- **Profile rewritten against gsd-core.** Counts are now 72 commands, 65 agents, 29 hooks, 46 capabilities, and 18 runtimes (Gemini CLI removed). New material covers the capability plugin system, install profiles, blocking guard hooks, and the expanded `<task>` schema. A `## Changes since the previous pin (2026-05-31 → 2026-11-23)` section summarizes the move.

## Under the Hood

- The old pin `bdcaab2c752d` is not in gsd-core's history; the 2026-05-04 pin `61773332d61a` is. The README's commit count (4414) is measured from that earlier pin.
- Every path the profile cites was checked with `git -C gsd-core cat-file -e HEAD:<path>`.
- Frontmatter edits by hand: `slug`, `upstream`, `package`, `profile_path`, `summary`. The lede still holds, so `index.md` is unchanged. The `maintainer` key still reads `TÂCHES / gsd-build` and needs a decision.
- The Symphony profile's comparison table named GSD's maintainer as TÂCHES / gsd-build; it now names OpenGSD.
