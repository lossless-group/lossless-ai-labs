# The Open Specs Study's Profiles Carry the Kit's Metadata Template

## Why Care?

[[2026-11-01_01]] made `open-specs-and-standards/context-v/` an Open Knowledge Format bundle. This pass brings the same 14 docs up to the Context Vigilance Kit's frontmatter template, so a workflow dashboard or the corpus roll-up can title, date, attribute, and group them without guessing.

## What's New?

- **Every profile is `Reference`.** Each one describes a pinned upstream spec or tool as studied, which is what the kit's `Reference` status means: a doc agents consult. The one inquiry, a set of open questions with no answers yet, is `Draft`.
- **Titles on all 13 profiles**, from each doc's H1 (`OpenSpec — Profile` and so on). Their existing `name:` keys stay as they were.
- **Authors on all 13 profiles**, from their only human committer.
- **`date_modified` on all 14 docs**, from each file's last commit before this sweep, and a `date_created` on the inquiry from its first commit.

## Under the Hood

- Part of the tree-wide OKF sweep; see the Context Vigilance Kit's plan, [[Retrofit-Every-Repo-to-OKF-Then-the-Kit-Frontmatter]], and the status vocabulary in the context-vigilance skill's `status-discipline.md`.
- Every edit was made by hand, frontmatter only: 68 added lines, nothing removed. No body line changed, no existing date moved, and today's date was written into no existing doc.
- None of the docs had tags, a `version:` key, or a bare-string author, so no existing value needed normalizing.
- The inquiry's frontmatter has a misspelled `date_crated:` key. It was left in place, as an unknown key, beside the new `date_created:`.
