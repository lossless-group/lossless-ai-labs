## Why Care?

The kit gave ledes a length budget but never said what they could contain. About
174 ledes on one splash carried Markdown, which showed up as literal symbols.

## What's New?

- **The rule is written down:** a lede is a string, with no backticks, asterisks,
  links, or wikilinks. The fix belongs in the lede, not the renderer.
- **Compliance sweeps enforce it:** they remove the markup and keep the words.
- **The README now covers versions and ledes,** including the three version
  formats a doc can use.
