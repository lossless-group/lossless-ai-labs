# Context Vigilance Kit v0.4.0: Skill Packs, Floorplan, and a Search That Reaches the Corpus

## Why Care?

More and more of the best agent skills are someone else's: a pack on one theme, or one developer's whole setup. Until now the kit said nothing about where they go, and copying one in had real costs: we broke our own corpus build doing it. This release gives them a home, with a rule simple enough to follow without thinking.

## What's New?

### Highlights

- **Skill packs.** A single skill someone else wrote goes in `agent-skills/<name>/` as a git submodule, and loads like one of yours. A pack of several skills goes in `skill-packs/<name>/`, also as a submodule, with `skill-packs/README.md` saying where it comes from, why it's there and what it does. Never copied files. The `context-vigilance` skill and the folder guide carry the rule, and a [new pattern page](https://context-v.dev/patterns/skill-packs/) explains why, with packs from Garry Tan, Matt Pocock, and one drawn from Andrej Karpathy's notes.
- **Floorplan is a recommended companion**, beside Graphify, Archify and the Chroma skills. It draws an interactive, plain-language map of a codebase, or a blueprint from a PRD before any code exists. Install it from [its own repo](https://github.com/haydenschmitty/floorplan).

### Changed

- **The survey skips skill packs.** It reads `skill-packs/README.md` and nothing inside a pack, and no longer lists a pack among the tree's repos.
- **Search can hand off to the corpus.** The site's search page takes `?q=` and keeps the URL in step as you type. Below the results, a link carries your query to the [corpus](https://lossless-group.github.io/context-v-corpus/), which searches 1,000+ context-v docs from our own projects. `context-v.dev/corpus` is a short link there.
- **context-v.dev is the site's only address.** The GitHub Pages copy is retired, so search engines see one set of pages, and the site has its own analytics, separate from the corpus.

### Also

- The `docs-v` spec: docs split by who reads them, kept current by agents, served live on Starlight. Agent-facing docs stay experimental and off by default. A spec only; nothing ships yet.

## Upgrade

In Claude Code, run `/cv:upgrade` (or `/plugin update cv@context-vigilance-kit`), then start a new session so the updated skills load. Nothing in an existing `context-v/` has to change. If you already keep someone else's skills as copied files, consider replacing them with a submodule, as the new rule describes.
