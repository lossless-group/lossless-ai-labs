## Why Care?

GitHub flagged 20 advisories in the site's dependencies (8 high), all in
`splash/pnpm-lock.yaml`. The site is static, so they mattered for the
build and the dev server, not for visitors. They're cleared anyway.

***

## What's New?

- **Astro 7.3.5 → 7.4.13**, which fixes the XSS through dynamic tag names
  and the image endpoint's file read.
- **The lockfile is refreshed within existing ranges**, so the packages
  pulled in by others are patched: undici 8.13.1 (eight alerts, including
  a TLS validation bypass), vite 8.3.8, smol-toml 1.9.1, source-map-js 1.2.4
  and zod 4.6.7.
- **The `package.json` floors** for @astrojs/sitemap, LFM and pagefind
  rise to the versions already installed.

`pnpm audit` reports nothing, the build is clean (58 pages), and pnpm 10
installs the lockfile frozen.
